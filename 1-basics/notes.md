# Basics

Compile and run .rs file

```
rustc main.rs
./main.rs
```

Create project with cargo

```
cargo new project_name
```

Or initialize existing project

```
cargo init project_name
```

---

_Cargo.toml_ file stores metadata and dependencies

Build project with cargo

```
cargo build 

// Or build for release with optimizations
cargo build --release
```

Quickly run for testing

```
cargo run
```

Check for errors without compiling

```
cargo check
```
